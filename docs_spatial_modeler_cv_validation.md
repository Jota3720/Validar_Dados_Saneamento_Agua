# Guia rapido para Spatial Model Editor

- Entrada: diretorio do projeto.
- Execucao: chamar o script Python que gera os outputs de validacao.
- Saida: apontar para o ficheiro final de erros produzido pelo pipeline.

O modelo SM nao deve editar a BD Oracle. Deve apenas orquestrar a execucao do validador e abrir os outputs no GeoMedia.
